Rules from three files

This page links one stylesheet, which imports another. The imported sheet's rules come first, so the importing sheet's heading colour and panel background win over the ones it inherited — reversing that order inverts every override a site relies on.

A @media print block would hide this text entirely if it applied, and it does not. A min-width query that the viewport satisfies puts the eight-pixel border round this panel; a max-width one it does not satisfy, and an orientation query that cannot be measured, would both paint it red.
