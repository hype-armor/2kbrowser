Styling before stylesheets

The era's markup carries most of its styling in attributes rather than CSS, so a browser that only reads stylesheets renders these pages as unstyled text.

This paragraph is aligned by an align attribute, with no CSS involved.

A font element sets colour, face, and size at once, and the text around it is unaffected.

An author rule beats a presentational hint on the same element, so this line is green rather than red.

Attribute Effect
bgcolor background colour
align text alignment
cellpadding padding inside every cell
border a rule around the table and each cell
A table used for page layout, not for data, draws no rules.
